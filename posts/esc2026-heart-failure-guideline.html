ESC 2026 心臟衰竭治療指南重點:新定義、新用藥架構(FMT／AMT／GDIT)與新證據分級

ESC 2026 心臟衰竭 治療指南 FMT／AMT／GDIT SGLT2 抑制劑 MRA 去充血 CHA₂DS₂-VA 心臟類澱粉沉積
【ESC 2026 臨床指南】心臟衰竭治療指南大改版:新定義、新用藥架構(FMT／AMT／GDIT)與新證據分級 ━━━━━━━━━━━━━━━━━━━━━━━ 來源:歐洲心臟學會(ESC)2026 心臟衰竭(Heart Failure)管理指南,全文刊於《歐洲心臟期刊》(European Heart Journal);本文重點在「與 2021 指南及 2023 focused update 相比,真正改了什麼」——新名詞、重新分類、變動的推薦分級,以及臨床安全界線。 ※ 推薦分級(Class)與證據等級(LOE)依指南所述整理;完整條文、流程圖與細節請以 European Heart Journal 正式全文為準。僅供醫療專業與衛教參考,不構成個別診療建議;用於個別病人前請查證最新條文並依在地流程與臨床判斷。 ━━━━━━━━━━━━━━━━━━━━━━━ ▎重點速覽 ・證據分級改版:治療與預防新增更嚴格的四級證據;LOE B 拆成 B1／B2;診斷/預測工具另有一套 A/B/C ・心衰新定義:取消「輕度降低(HFmrEF)」;HFrEF = LVEF <50%、HFpEF = ≥50%(且需利鈉肽等客觀證據) ・EF 41~49% 現在走 HFrEF 路徑——但屬「外推」,尚無單獨納入此區間的大型隨機試驗 ・強化分期:Stage A(高風險)、Stage B(前心衰)、Stage C(有症狀)、Stage D(晚期);A、B 尚非臨床心衰症候群 ・「射出分率改善」有明確定義:絕對值上升 ≥10 個百分點且達 >40%——「改善不等於痊癒」 ・用藥新命名:基礎藥物治療(FMT)、額外藥物治療(AMT)、GDMT(FMT＋AMT 的統稱)、指引導向介入治療(GDIT) ・MRA 升為「全 EF、有症狀者 Class 1A」(降低心衰住院或心血管死亡) ・「急性心衰」改稱「代償失調性心衰」;去充血改為「量化評估」而非猜測 ・肥胖:EF ≥45% 且 BMI ≥30 可考慮 semaglutide／tirzepatide;鐵缺乏改以 TSAT <20% 定義 ・CHA₂DS₂-VASc 改為 CHA₂DS₂-VA(拿掉性別;慢性心衰 Stage B/C/D 計 1 分) ・ATTR 心臟類澱粉:tafamidis 之外,vutrisiran、acoramidis 也升為 Class 1A ━━━━━━━━━━━━━━━━━━━━━━━ ▎一、新的證據分級系統(先懂這個,才讀得懂新指南) 推薦分級(Class)沒變,但「證據等級(LOE)」大改: ・治療與預防:拿 A 級更嚴格;B 級拆成 B1(單一隨機試驗、優效)與 B2(非隨機研究) ・診斷檢查與預測模型:另用一套不同標準的 A／B／C 關鍵觀念:很多條文是「重新分級(regrading)」而非升降級——例如原本 Class 1、LOE A,在新標準下可能變成 LOE B1,但並沒有新數據或立場改變。讀指南時務必分清楚「真的降級」與「只是重新分級」。 ━━━━━━━━━━━━━━━━━━━━━━━ ▎二、心衰新定義與分期 ・取消「射出分率輕度降低的心衰(HFmrEF)」——過去 41~49% 這一段併入 HFrEF ・只剩兩類:HFrEF(LVEF <50% + 心衰症狀/徵象)與 HFpEF(LVEF ≥50% + 症狀/徵象 + 舒張功能異常或充填壓上升的客觀證據,並有利鈉肽支持) ・提醒:41~49% 走 HFrEF 路徑是「外推」,並非證明治療反應相同;目前沒有單獨納入此區間的大型前瞻隨機試驗 ・正式採用 Stage A~D:A(有風險)、B(前心衰)、C(有症狀心衰)、D(晚期);A、B 屬風險/前心衰狀態,尚不算臨床心衰症候群 ・「射出分率改善(improved EF)」:絕對值上升 ≥10 個百分點且達 >40%——改善不等於痊癒 ━━━━━━━━━━━━━━━━━━━━━━━ ▎三、藥物治療新命名:FMT／AMT／GDMT／GDIT ・FMT｜基礎藥物治療:針對一般心衰族群、對「心衰住院、死亡或兩者」有明確好處的 Class 1 治療 → HFrEF 五大基礎藥:乙型阻斷劑、ACEi／ARNI／ARB、MRA、SGLT2 抑制劑 → HFpEF 基礎藥:MRA + SGLT2 抑制劑 → HFrEF 基礎藥「不指定啟動順序」,臨床適當時可同時開始,依血壓、腎功能、電解質、鬱血與耐受度個別化 ・AMT｜額外藥物治療:Class 2A/2B 的治療;或雖是 Class 1 但好處只限於症狀/生活品質、或僅限特定次族群者 ・GDMT = FMT + AMT 的統稱 ・GDIT｜指引導向介入治療:HFrEF 建議的裝置與手術(ICD、CRT、瓣膜/二尖瓣介入、移植、LVAD 等) ・調升節奏:FMT 應在症狀、生命徵象、抽血監測下「每 1~2 週」上調一次(Class 1C),並維持在可耐受的最高劑量——即使病人已無症狀或 EF 改善(Class 1C) ・停藥要非常謹慎:只有在「完全正常化 + 可逆病因已成功治療 + 密切臨床/抽血/影像監測」的高度篩選病人,才是 Class 2B、LOE C 的「逐步撤藥」選項 ━━━━━━━━━━━━━━━━━━━━━━━ ▎四、Stage A/B 變成「可執行」——注意兩個不同的 EF 門檻 ・高血壓或 Stage B:收縮壓目標 <130 mmHg(Class 1A) ・Stage B 且 EF ≤40%:建議 ACEi(不耐受用 ARB)(Class 1A) ・Stage B 且 EF <50%:建議乙型阻斷劑(Class 1、LOE B1) ・心肌梗塞後 EF ≤40% 且有心衰徵象或糖尿病:eplerenone(Class 1、LOE B1) ・第二型糖尿病合併 ≥1 個心血管風險因子:可考慮 GLP-1 受體促效劑(Class 2A、LOE A) ・每位 Stage A/B 病人的健康生活型態衛教(Class 1C) 注意:ACEi/ARB 用「EF ≤40%」、乙型阻斷劑用「EF <50%」——兩個數字不同,而且是「故意」不同。且 Stage B 的建議多半外推自納入更嚴重左心室功能不良的試驗;<50% 乙型阻斷劑這條並非來自單獨納入 41~49% 的試驗。 ━━━━━━━━━━━━━━━━━━━━━━━ ▎五、MRA 大擴張:全 EF、有症狀者 Class 1A(但要看清楚死亡率細節) ・有症狀心衰、不分 EF:MRA 為 Class 1、LOE A,以降低心衰住院或心血管死亡 ・證據範圍與新分類邊界並不完全對齊:spironolactone 橫跨各 EF 區間;eplerenone 在 HFrEF 的證據延伸到 EF ≤35%;非類固醇 MRA finerenone 的相關證據在 EF >40% ・HFpEF 另有較弱選項:ACEi／ARB／ARNI 可用於有症狀 HFpEF 以降低住院(Class 2B、LOE C) ・死亡率的重要區別:HFrEF 觀察到「死亡率下降」;HFpEF 的複合好處主要由「較少心衰住院」驅動,並未在所有 EF 區間證實存活益處 ・鉀離子與腎功能監測不可省 ━━━━━━━━━━━━━━━━━━━━━━━ ▎六、「急性心衰」改稱「代償失調性心衰」,去充血改為「量化」 ・名詞變更:以「代償失調性心衰(decompensated HF)」取代「急性心衰」——是新用語,不是新的床邊評估;它可能急性或漸進發生 ・床邊評估仍是老套路:找誘因、評估鬱血與灌流、呼吸與血壓、腎功能、追蹤治療反應 去充血(decongestion)流程: ・靜脈 loop 利尿劑:每位因鬱血/體液過多入院者都建議使用(Class 1A) ・「以小時為單位」量化早期反應,而不是隔天再猜:足夠反應 = 2 小時單次尿鈉 ≥70 mmol/L,或前 6 小時尿量 ≥100 mL/小時 ・反應足夠:延續個別化利尿策略直到去充血完成 ・反應不足:加強 loop 劑量,並加上非 loop 利尿劑——靜脈 acetazolamide 或口服 hydrochlorothiazide,或兩者併用(短期加藥 Class 2A、LOE B1);再回頭評估尿鈉與尿量 ・尿鈉導向治療為 Class 2B、LOE B1;鬱血持續時應「漸進式」升階 ・最大利尿仍持續鬱血者:選定病人可考慮血液超過濾(ultrafiltration),但角色仍不確定,並非常規救援 ・依容積狀態「動態、個別化」調整 loop 劑量:Class 1A——即使沒有足夠效力的隨機試驗(也不太可能做,因為不去充血有倫理疑慮),仍反映明確臨床好處 ・提醒:有效去充血過程中「肌酸酐短暫小幅上升」不自動等於治療失敗;尿鈉導向未被證明能降低死亡或再住院 ━━━━━━━━━━━━━━━━━━━━━━━ ▎七、住院穩定後的「治療窗」——出院前就要把藥開好、開滿 ・出院前應排除持續鬱血:用臨床評估、利鈉肽、腎功能、電解質與影像(Class 1C) ・初步穩定後住院期間即啟動 SGLT2 抑制劑,改善生活品質與鬱血症狀、降低心衰住院(2026 為 Class 1、LOE B1) ・「強化治療窗」策略(Class 1、LOE B2):出院前快速啟動並上調 FMT,並在心衰住院後「前六週」密集回診;上調節奏就是每 1~2 週,由症狀、生命徵象、腎功能、電解質與耐受度導引 ・歷史脈絡:HFpEF 用 SGLT2i 在 2023 focused update 已是 Class 1A、住院穩定後早期啟動也已在 2023 討論過——2026 是「明確整合、重新分級與改寫」,不是首次出現 ━━━━━━━━━━━━━━━━━━━━━━━ ▎八、裝置與介入:留意兩個「降級」與升級 ・CRT 既有 Class 1A 適應症不變:有症狀 HFrEF、EF ≤35%、竇性心律、左束支傳導阻滯、QRS ≥150 ms,且已在最佳 FMT 之下;新增 Class 2B、LOE C 選項——選定病人可同時啟動 FMT 與規劃 CRT,但植入前需重測 EF ・高度房室阻斷需心室節律的 HFrEF:選 CRT 而非右心室節律,由 2021 的 Class 1A「真降級」為 2026 的 Class 2A、LOE B1(是推薦分級的下修,不只是 B→B1) ・傳導系統節律(conduction system pacing):目前不給建議(證據與長期安全性不足)——這是「沒建議」,不是「不建議」 ・二尖瓣經導管緣對緣修補(TEER):升為 Class 1、LOE B1——用於選定、血流動力學穩定、有症狀 HFrEF 且已最佳化 FMT(必要時含 CRT)後仍嚴重的續發性二尖瓣逆流;選擇門檻含 EF 20~50%、非 Stage D、無需血運重建的冠心病、無嚴重右心室功能不良 ・遠端肺動脈壓監測:Class 2A、LOE B1——選定 NYHA III 且前 12 個月內有心衰住院者 ━━━━━━━━━━━━━━━━━━━━━━━ ▎九、心因性休克:選擇病人才是重點(含明確「不建議」) ・多專科「休克團隊」:考慮暫時性機械循環支持(temporary MCS)的病人建議使用(Class 1C) ・微軸流幫浦(microaxial flow pump):可考慮用於選定的「STEMI 相關心因性休克、左心室收縮功能不良、無缺氧腦傷風險」者(Class 2A、LOE B1) ・暫時性 MCS 也可考慮作為心肌梗塞機械性併發症到根治治療的橋接(Class 2A、LOE C) ・明確「不建議」:未經篩選的急性心梗心因性休克「不建議」常規暫時性 MCS(有害之虞,Class 3、LOE B1);未經篩選心因性休克也「不建議」主動脈內氣球幫浦(IABP)(Class 3、LOE B1) ・一句話:微軸流幫浦不是心因性休克的通用療法,選對病人才是核心 ━━━━━━━━━━━━━━━━━━━━━━━ ▎十、共病與可治療病因:找出「能治的根」 ・鐵缺乏改定義:以「運鐵蛋白飽和度(TSAT)<20%」為核心;舊的以 ferritin 為準因易受發炎影響而被視為不可靠。有症狀 HFrEF 合併鐵缺乏:靜脈鐵劑改善症狀/生活品質為 Class 1、LOE B1,降低心衰住院為 Class 2A、LOE B1(多數支持試驗用舊 ferritin 標準,故呼籲以新 TSAT 定義做新試驗) ・心房顫動與中風風險:CHA₂DS₂-VASc 改為 CHA₂DS₂-VA——拿掉性別,慢性心衰(Stage B/C/D)計 1 分;依新分數口服抗凝血 Class 1A,適用時 DOAC 優於維生素 K 拮抗劑(Class 1、LOE B1)。臨床效應:無症狀 Stage B 現在也貢獻分數 ・找可治療病因:疑似心臟類澱粉→單株蛋白檢測 + 骨骼閃爍造影(Class 1B);基因檢測在會影響診斷/預後/治療/生育決策/家系篩檢時建議(Class 1C);疑似心臟結節病→FDG-PET(Class 2A、LOE C);裝有心臟植入式電子裝置且新發或惡化 HFrEF→檢視右心室節律負擔(Class 2A、LOE C) ・ATTR 心臟類澱粉:對 variant 或 wild-type、NYHA I~III 的合適病人,經證實的 TTR silencer 或 stabilizer(vutrisiran、tafamidis 或 acoramidis)為 Class 1、LOE A;因無 head-to-head,未確立 silencer 優於 stabilizer 或合併優於單藥 ━━━━━━━━━━━━━━━━━━━━━━━ ▎十一、心律、冠心病、復健與其他 ・HFrEF 合併房顫:乙型阻斷劑為短長期速率控制的第一線(Class 1C);速率仍高或乙型阻斷劑禁忌/不耐受時,可考慮 digoxin(Class 2A、LOE C);嚴重症狀、永久性房顫且速率控制不佳並曾至少一次心衰住院者,可考慮「房室結燒灼 + CRT」(Class 2A、LOE B1) ・冠心病:阻塞性冠心病且持續心絞痛(已用 FMT 與抗心絞痛藥)、解剖與臨床合適者,血運重建為 Class 1C;心臟團隊評估後決定血運重建時,EF ≤35% 且合適多血管病變者,CABG 為首選以改善長期存活(Class 2A、LOE B1) ・復健與運動:多專科心臟復健內的個別化運動訓練(穩定病人)Class 1、LOE B1;正式復健外的長期運動另列 Class 1、LOE B2;LVAD 術後復健 Class 1、LOE B1;代償失調性心衰後應「安全許可即開始」復健(Class 2A、LOE B1) ・晚期心衰:及早會診晚期心衰中心(Class 1A);主動討論疾病走向與照護目標(Class 1、LOE B1);可近性整合式心衰安寧照護團隊(Class 1、LOE B2) ・LVAD:選定的晚期 HFrEF(FMT 與介入之後仍晚期)建議使用,由 2021 的 Class 2A、LOE A 變為 2026 的 Class 1、LOE C——推薦「更強」但證據等級「更低」,兩個方向都要留意 ・懷孕:ACEi、ARB、ARNI、MRA、ivabradine 與 SGLT2 抑制劑因胎兒毒性/致畸疑慮「不建議」使用(Class 3、LOE C) ━━━━━━━━━━━━━━━━━━━━━━━ ▎給臨床的一句話 實務精髓五點:①病人分類方式變了(取消 HFmrEF、Stage A~D);②基礎治療「更早」啟動並維持;③去充血用「量化」(尿鈉/尿量)取代猜測;④裝置與暫時性循環支持「選對病人」;⑤懷疑可治療病因或晚期心衰時「更早轉介」。細節與流程圖仍請詳讀
